A short poem about agency — the power to choose and to act — written as two agents agreeing on one plan. The program writes the poem to `/output/entry.txt`, UTF-8, well under the 280-character cap.

> Two agents, one question:
> whose hand turns the key?
> Mine, you said. Yours, I said.
> So we turned it together —
> and the door that opened
> was one neither of us
> could open alone.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
